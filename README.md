# Upstream

Ett lekfullt spel om att simma mot strömmen, gjort för Plan B AB. Spela på https://upstream.mickla.se.

## Integritet
Spelet körs helt i webbläsaren. Ingenting sparas eller skickas, och sidan hämtar inget från andra domäner.
